# Mr AI Studio

AI content production studio website for MR AI Studio.

## Stack
- Next.js App Router
- React
- CSS
- Vercel-ready

## Project chat
The site includes a messenger-style project chat UI. It is currently a polished frontend demo; the next step is connecting it to a real-time backend (Supabase is a good fit) so client messages persist and can be managed from an admin inbox.

## Run
npm install
npm run dev
